fix(ci): fix postgres connection in tests and add test_jobs.py to test suite

## What changed
- Added `postgres:15-alpine` service to the `lint-and-unit` job in `.github/workflows/ci.yml`.
- Added an `alembic upgrade head` step in `lint-and-unit` before tests run, to populate the database schema.
- Added `tests/test_jobs.py` to the explicitly invoked list of test files in `ci.yml`.

## Why
- `tests/test_pipelines.py` endpoints recently gained `db: AsyncSession = Depends(get_db)` from ownership recording in submit functions. Running the test suite locally or in CI without a live database but with `TestClient(app)` (which evaluates dependencies) caused the tests to fail with `ConnectionRefusedError` (connecting to `localhost:5432`). Adding the service in CI resolves the failure.
- `test_jobs.py` was introduced in a prior commit but missing from the explicit CI pytest run command.

## Verification
- Verified by checking the GitHub Actions configuration against the expected services and commands.

## Risk
- Low. This change only updates CI infrastructure and doesn't modify application logic.
